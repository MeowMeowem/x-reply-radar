# X Reply Radar 热帖回复雷达

**找到现在最值得回的 X 帖子，用你自己的语气回。**

[English](README.md)

它跑在你自己的电脑上。它会读你的 X 首页、趋势和你关注的官方账号，按帖子起量的速度排序，再帮你写回复。回复之所以像你，是因为它学的是你真实发过的内容。回复、引用、发帖都是一键完成；你不点，什么都不会发出去。

- **热帖**：把「为你推荐」按浏览增速和互动增速排好序，标出阶段（刚起量 / 正在爆 / 已经太晚），让你赶在还有意义的时候回。
- **每条帖子给两条回复**，旁边标着「像不像你」的分数。可以先改再一键回复，也可以勾选几条一起发。
- **趋势**：X「探索」里的热门话题。可以一键去 X 搜索，也可以让 AI 围绕这个话题写一条帖子。
- **官方动态**：你关注的官方账号（比如 `OpenAI, AnthropicAI`）的新帖，加上官方博客、RSS 和论文。每一条都能一键写引用帖。
- **发帖**：自己写，或者让 AI 按你的语气改。每天还会自动写一批引用帖草稿。
- **学你的风格**：从你的主页或 X 数据存档里学习，也会记下你每一次对 AI 草稿的修改。每周整理一次风格笔记；新版本评测分数不比旧版低，才会启用。
- **契合度评分**：用留一法评测，也就是 AI 在看不到你真实回复的情况下来写，再和你的真实回复对比。分数的变化会画成曲线。
- **默认安全**：点发送只会打开 X 的发帖页，内容已经填好，由你自己按「发帖」。自动发送要手动开启，并且有排队和限速。
- 界面和写作都支持中文、英文。

## 快速开始

需要 Python 3.10 以上，外加一个 OpenAI 兼容接口的 API Key（OpenAI、Anthropic、OpenRouter、DeepSeek、本机的 Ollama 都行）。

```bash
git clone https://github.com/MeowMeowem/x-reply-radar.git
cd x-reply-radar
./start.sh          # macOS / Linux。macOS 也可以直接双击 start.command
```

Windows：右键 `start.ps1`，选「使用 PowerShell 运行」。

第一次运行会自动建虚拟环境、装依赖和无头浏览器，然后打开 <http://127.0.0.1:8796>。剩下的按「设置」页的引导走：

1. **登录 X**：粘贴 Cookie（方法见下面）。点「测试登录」会顺便把你的 handle 填上。
2. **配置 AI**：选服务商，填 Key 和模型，点「测试」。
3. **写人设**（学习 → 你的资料）：你是谁、平时怎么说话。写得越具体，回复越像你。
4. 点「抓取我的主页」或「导入 X 存档」，让它从你的真实帖子里学习。

### 怎么拿到 X 的 Cookie

1. 用电脑浏览器登录 x.com。
2. 按 F12（Mac 按 ⌥⌘I）打开开发者工具，依次进入「Application / 应用」（Safari 叫「储存空间」）→ Cookies → `https://x.com`。
3. 把 `auth_token` 和 `ct0` 两项的值复制出来，按 `auth_token=…; ct0=…` 的格式粘贴。

也可以粘贴 Cookie 扩展导出的 JSON，或者整段 `Cookie:` 请求头。Cookie 就是你的登录状态：它只保存在你本机的 `.env` 里，不会写进日志，也只会发给 x.com。

## 发送方式

| 通道 | 怎么发 | 取舍 |
|---|---|---|
| **在 X 里确认后发**（默认） | 打开 X 的发帖页，内容已经填好，你自己按「发帖」 | 完全没有自动化；每条会开一个标签页 |
| **后台自动发（Cookie）** | 无头浏览器带着你的 Cookie 打开同一个页面，替你按「发帖」 | 免费，支持批量；但属于自动化操作，频率要设得保守 |
| **X 官方 API** | 用你自己申请的开发者密钥调用 `POST /2/tweets`（OAuth 1.0a） | 最稳定、最合规；X API 要付费 |

所有发送都要排队，两条之间有最短间隔，还有每小时、每天的上限（默认 90 秒、每小时 10 条、每天 40 条）。如果已经按了「发帖」，结果却没回来，这条会直接标为失败，不会自动重试，所以不会发重复。

> **请注意**：X 对自动化操作有[专门的规则](https://help.x.com/en/rules-and-policies/x-automation)。本项目不会在你没操作的情况下发出任何回复；但在「后台自动发」模式下，你把内容放进队列之后，就由程序替你按「发帖」。别拿它刷屏，限速尽量设低一点。本项目与 X Corp 没有任何关系。

## 它怎么学你的风格

- **人设**（`profile/persona.md`）由你自己写，每次生成都会带上。
- **例句**：你最近 30 条真实回复（原帖 → 你的回复）。
- **你的修改**：你改过 AI 草稿再发出去，就会记下一组「AI 写的 → 你实际发的」，再给模型看。这是最有用的信号。
- **风格笔记**（`profile/style_notes.md`）从你的帖子里学出来。每隔 `CONSOLIDATE_EVERY_DAYS` 天整理一次，把新帖子、你的修改、你不要的草稿都合进去。
- **契合度评分**：固定取一组你的真实回复，让 AI 在看不到你原话的情况下来写，再由评委打 1～10 分。新版本的笔记分数不比当前版低，才会启用。学习页会画出分数曲线，旁边是「不学习」的对照线，学得有没有用一眼就能看出来。
- 从这里发出去、由 AI 起草的内容，**不会**被当成你本人写的，所以模型不会拿自己写的东西来学自己。

另外，每条建议回复生成时都会打一次分，低于 `FIT_MIN_SCORE` 的会重写一次。

## 你的数据

| 位置 | 内容 |
|---|---|
| `.env` | 设置和密钥（权限 600） |
| `profile/` | 人设、经历、风格笔记，以及自定义的 prompt、`topics.json`、`sources.json` |
| `data/radar.db` | SQLite：抓到的帖子、你的帖子、草稿、发送队列、评测记录 |
| `logs/` | 日志，里面的凭据都会被替换成 `***` |

这些都在 `.gitignore` 里。服务只监听 `127.0.0.1`，用其他主机名来访问会被拒绝，跨站请求也会被拦截，所以别的网站既读不到你的数据，也没法借它替你发帖。发给 AI 服务商的只有帖子正文和作者名。

## 自定义

- **Prompt**：把 `prompts/<语言>/` 里的任意文件复制到 `profile/prompts/`，改那一份。
- **排序用的主题和屏蔽词**：把 `config/topics.json` 复制到 `profile/topics.json`。
- **消息源**：把 `config/sources.json` 复制到 `profile/sources.json`。支持 RSS、Hugging Face 论文，也支持任意列表页（按链接规则抓）。
- 所有选项都列在 [`.env.example`](.env.example) 里，大部分也能在「设置」页改。

## 后台常驻

macOS 用 launchd，配置写法见[英文说明](README.md#running-in-the-background)；Linux 用 systemd 用户服务执行同一条命令即可。记得设置 `OPEN_BROWSER=0`。

## 开发

```bash
.venv/bin/pip install -r requirements-dev.txt
.venv/bin/python -m pytest -q
```

前端是 `static/` 里的原生 JavaScript，不需要构建，文案在 `static/i18n.js`。读取 X 的方式是截获 X 网页自己请求的 GraphQL 响应（`scraper/parse.py`），所以 X 改了数据结构，通常只要改这一个文件。测试用的是手写的样例数据。
